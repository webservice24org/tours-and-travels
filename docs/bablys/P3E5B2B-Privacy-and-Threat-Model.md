# P3E.5B.2B — Privacy/security invariants

- **Session + CSRF:** all mutations and secret-backed reads use `POST` under Laravel's `web` middleware. Browser secret-bearing status calls are same-origin JSON requests with a Laravel CSRF header.
- **Guest secrets:** P3E.5B.2A stores SHA-256 digests only. The two generated 256-bit secrets are sent to email once. Fragment-style links prevent them from being sent in initial GET requests, and React removes fragments from browser history immediately. The verification endpoint never changes state on GET.
- **Guest authorization:** reference alone is not enough. A guest status read requires both email proof (`verified` state) and a valid separate access token. Requests after withdrawal/booking conversion intentionally lose access because the 2A manager clears hashes.
- **Customer authorization:** account requests use the authenticated, email-verified `User`; input name/email is not trusted for identity. Collection reads and mutation queries are filtered by owner ID. Staff permissions are not granted implicitly by account login.
- **Staff contact PII:** only `tours.edit` + `tours.publish` staff can access the decrypting review controller. Do not enable listing for `tours.view` or generic account users. Add dedicated booking permissions before broadening access.
- **Persistence:** request contact fields stay encrypted under `APP_KEY`; only email lookup HMAC and token hashes are indexed. Consent timestamp and version are recorded by additive migration. Avoid logging request bodies, token-bearing fragments, encrypted attributes, guest email links, PII or mail objects.
- **Anti-abuse:** strict server validation and published-tour checks; `throttle` middleware plus hourly email/IP/account counters; per-session UUID idempotency backed by a unique hash. Tokens are never returned as PHP `TourBookingRequestReceipt` JSON.
- **Delivery/availability:** mail delivery is synchronous by design for one-time guest secrets; production `log`/`array` mail drivers are blocked. Send failures result in a withdrawn inaccessible request. Additional retry/outbox/alerting is planned. No request reserves inventory.
- **Nonbinding money:** only P3E.3 authoritative calculator supplies preview; amounts are integer minor units plus ISO currency. The client cannot set prices or seats. Any staff conversion is outside public routes and must recheck source pricing and available capacity.
- **Retention & legal:** consent copy is versioned but the final approved privacy notice, contact-retention duration, subject access/deletion flow, operational email/retry policy and consent audit remain launch gates. Avoid deploying until the business approves them.
